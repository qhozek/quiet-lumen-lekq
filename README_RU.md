# HerokuSafe 2.2.0

Форк Telegram-юзербота Heroku/Hikka. Новые изменения оригинала не считаются доверенными автоматически.
Это защита цепочки обновлений, **не изоляция установленных модулей**.

[Полная инструкция](README.md) · [Безопасность](SAFETY.md) · [Изменения](CHANGELOG.md)

## Установка

Нужны Python 3.10+ и собственные `api_id` / `api_hash` Telegram.
Для Linux / WSL желательно использовать отдельного пользователя без root.

```bash
git clone https://github.com/qhozek/quiet-lumen-lekq.git Heroku
cd Heroku
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python -m heroku
```

Либо скачайте и проверьте `install.sh` именно из этого репозитория и выполните `bash install.sh`.
Установщик оригинальной Heroku устанавливает другую сборку.

## Обновления

Источник ядра — только `qhozek/quiet-lumen-lekq`, ветка `master`.
Уведомления включены по умолчанию, автоматическая установка выключена. Обновление: `.update`.
Локальные изменения не сбрасываются; незнакомый `origin` не переписывается автоматически.

Старые установки получат стандартное уведомление после публикации, если уже смотрят на этот форк,
онлайн, имеют рабочий inline-бот и не отключили уведомления. Нельзя новым коммитом изменить
настройки репозитория у уже работающего чужого процесса.

Проверьте `git remote get-url origin`. Перед миграцией остановите бот и сделайте приватную резервную копию.
Если требуется перенастройка, после проверки локальных изменений:

```bash
git remote set-url origin https://github.com/qhozek/quiet-lumen-lekq.git
git pull --ff-only origin master
```

Если история Git несовместима — не используйте принудительный сброс. Установите свежую копию
и перенесите только проверенные данные. Сессии, токены и базы аккаунтов нельзя публиковать.

Docker собирается из текущего checkout, а не клонирует оригинал. Для обновления обновите checkout,
пересоберите образ и пересоздайте контейнер. Данные остаются в томе `/data`, код — в `/opt/HerokuSafe`.
Git-обновления внутри контейнера выключены.

## Важно

- Нет удалённого allow-list, принудительного переключения ветки/выхода из аккаунта и чужих анонсов.
- URL-модули стартуют из одобренного локального кеша; новый код требует подтверждения.
- Старые разрешения «обновлять всегда» игнорируются; если доверенного кеша нет, нужна ручная `.dlmod`.
- Библиотеки кешируются и не обновляются молча при рестарте.
- Защита API включена по умолчанию; сохранены маскирование токенов и защищённая запись файлов.
- Вручную установленный модуль всё ещё имеет доступ к аккаунту и системе. Абсолютной гарантии безопасности нет.

Тесты без Telegram: `python -m pip install pytest`, затем `python -m pytest tests -q`.
